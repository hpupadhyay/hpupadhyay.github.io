NeuralProxy

Cut LLM API costs with routing, caching and live spend tracking

Built - Pre-Release

About

NeuralProxy sits between your app and the LLM providers you use, and finds the cheapest option for each request without you rewriting anything. Point an existing integration at the proxy instead of a provider endpoint, and routing, caching and cost accounting happen underneath it. Typical saving is 30-50% of API spend without changing what the model is asked to do.

How It Works

  • Add your API keys for the providers you already pay for
  • Send requests through NeuralProxy instead of directly to a provider
  • NeuralProxy routes each request to the cheapest provider that can serve it
  • Identical requests are served from cache instead of billed again
  • Watch the savings accumulate on the dashboard

Multi-Provider Support

  • OpenAI, Anthropic, Google Gemini, Mistral and Groq
  • Smart routing picks the cheapest available provider per request
  • One integration surface, so switching or adding a provider is configuration

Response Caching

  • Identical prompts are served from cache rather than sent again
  • The largest saving on workloads with repeated or templated prompts
  • Savings are counted, not estimated, so the dashboard reflects real avoided spend

Cost Dashboard

  • Real-time spending tracking and analytics
  • Per-request cost, per-provider cost, and total avoided spend
  • Prompt optimization tools, including token counting and compression suggestions

Security & Privacy

  • API keys stored in the Android Keystore, never in plain preferences
  • All data stored locally on your device
  • No analytics, no tracking, no accounts
  • Keys are only ever used to call the provider you configured

Requirements

  • Android 8.0 (API 26) or higher
  • Internet connection for API calls
  • API keys from one or more supported LLM providers

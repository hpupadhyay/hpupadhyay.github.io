Bar Code Scanner

Serverless barcode scanner that types straight into your PC

Early Access - Testing

About

A standalone barcode scanner built for stock counters, warehouse staff and anyone who types barcodes all day. The scanning engine is bundled in the app, so it works with no server, no backend, no account and no internet connection. Scanned values are typed into your PC over a Bluetooth HID keyboard, so the app you already use needs nothing installed on the desktop.

Scanning

  • Camera scanning via CameraX with on-device ML Kit decoding
  • Multi-scan reports every code in frame, not only the first
  • Detection overlay boxes each code while it is in view
  • Format filtering, where an empty selection means every format
  • Check-digit validation for EAN-13, EAN-8, UPC-A and UPC-E, off by default, showing the expected digit on a mismatch
  • Zoom slider clamped to the device's real maximum, and tap to focus from the tapped point
  • Torch, scan beep and vibration feedback

Batch Mode

  • Three modes - single review, add-and-continue, and send the whole batch
  • Per-value repeat counting, so a stock count of identical barcodes reads as one row with a count
  • A value must agree across three sightings within 400 ms before it is sent, so an unstable read is never typed into the PC
  • A genuine second label entering the frame is still accepted immediately
  • A failed send keeps the batch for retry instead of discarding it
  • Configurable separator between values - newline, tab, comma, semicolon, pipe, space or nothing

Sending To A PC

  • Bluetooth HID keyboard output to a paired computer
  • Send suffix of none, Tab or Enter, with Enter as the default
  • Capital letters and shifted symbols are sent correctly
  • Widened hold and release gap so a dropped Bluetooth report cannot leave a key stuck down and auto-repeating
  • Prefix and suffix payload templates

Find And Pick

  • Target list that accepts only listed values and ignores everything else silently
  • Built for picking against a known stock file rather than free scanning

Export & History

  • Batch export as CSV, TSV or JSON through the share sheet, with RFC 4180 quoting
  • Local scan history with re-send
  • Manual entry keypad with numeric and alphanumeric layouts
  • Empty barcode payloads are rejected instead of sent

Requirements

  • Android 7.0 (API 24) or higher
  • Bluetooth for sending to a PC; scanning works without it
  • Camera permission
